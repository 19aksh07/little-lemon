# Little Lemon Android Application

Little Lemon is a mobile application for a Mediterranean restaurant. This project is the capstone for the Coursera Android Developer Professional Certificate.

## Project Description

The application provides a platform for users to browse a restaurant menu and manage their personal information. It includes a user registration flow and a dynamic menu interface.

## Key Features

1. Onboarding: A registration screen where users provide their name and email address to access the app.
2. Home Screen: A menu page featuring a search bar, category filters, and a list of food items with descriptions and prices.
3. Profile Screen: A page that displays user details and allows them to log out of the application.

## Design Reference

The project was built based on a design system and mockups exported from Figma. The file `wireframe-components.png` in the project root shows the design components, color palette, wireframes and final mockups used for implementation.

## Technical Details

The app is built using modern Android development tools. It uses Jetpack Compose for the user interface, Kotlin for the application logic, and standard Android libraries for navigation and data storage.
